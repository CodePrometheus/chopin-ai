# chopin-ai

A coding agent built to improve itself.

```bash
npm install -g chopin-ai
cd my-project
chopin
```

Requires Node.js 24.8 or later. The first run connects a provider, by its sign-in or an API key, and picks a model;
`/hotkeys` lists the keys. `chopin web` opens the same conversation in the browser, and `chopin acp` serves it to
editors.

Features, configuration and what comes next are in the [repository](https://github.com/CodePrometheus/chopin-ai).
